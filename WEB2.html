HTML5 Sınav Çalışma ve Özet Rehberi

Önce Kod, Sonra İşlev - Sınav Öncesi Hızlı Tekrar Sayfası

⭐ SINAVDA DİREKT KULLANABİLECEĞİN ŞABLONLAR

A. Dış CSS Bağlama ve ID Kullanımı

Hoca "CSS'i ayrı dosyaya yaz ve ID ile çağır" derse, head etiketinin içine şunu yazacaksın:
<link rel="stylesheet" href="stil.css">

HTML'de kutu oluştururken: <div id="kapsayici">...</div>
CSS dosyasında ise: #kapsayici { width: 800px; margin: 0 auto; }

B. Yatay Menü (Navbar) Yapımı

<ul id="yatay-menu">
    <li><a href="index.html">Anasayfa</a></li>
    <li><a href="hakkimizda.html">Hakkımızda</a></li>
    <li><a href="iletisim.html">İletişim</a></li>
</ul>
CSS Mantığı: ul etiketine list-style-type: none; verip noktaları kaldırırsın. li etiketlerine float: left; vererek yan yana dizersin. Linklerin alt çizgisini text-decoration: none; ile kaldırırsın.

C. Form ve Input Elemanları

<div class="form-grubu">
    <label>Adınız:</label>
    <input type="text" placeholder="Adınızı girin">
</div>
<div class="form-grubu">
    <label>E-posta:</label>
    <input type="email" placeholder="E-posta girin">
</div>
<button class="btn-gonder">Gönder</button>
CSS Mantığı: input elemanlarına width: 100%; padding: 8px; box-sizing: border-box; verirsen form çok şık durur. box-sizing: border-box; padding'in genişliği taşırmasını engeller.

D. İç İçe Div Yapısı (Nested Div Layout)

<!-- HTML -->
<div id="ana-kapsayici">
    <div id="ust-kutu">Üst İçerik</div>
    <div id="orta-kutu">Orta İçerik</div>
    <div id="alt-kutu">Alt İçerik</div>
</div>

/* CSS */
#ana-kapsayici { width: 800px; margin: 0 auto; background: #fff; padding: 20px; }
#ust-kutu { background: #3498db; margin-bottom: 15px; padding: 15px; }
#orta-kutu { background: #ecf0f1; margin-bottom: 15px; padding: 15px; }
#alt-kutu { background: #95a5a6; padding: 15px; }
CSS Mantığı: Dış kutuya margin: 0 auto; verilerek sayfanın ortasına hizalanır. İçteki kutuların birbiri üzerine yapışmaması için margin-bottom kullanılır (`padding-bottom` kutu içini büyütür, dış boşluk bırakmaz!).

1. DOCTYPE Etiketi

<!DOCTYPE html>
İşlevi / Ne Amaçla Kullanılır: Tarayıcıya bu belgenin en güncel HTML5 standardında yazıldığını bildirir. Sayfanın en başında yer alır.

2. HTML Kök Etiketi

<html lang="tr">
    <!-- Tüm HTML kodları buraya yazılır -->
</html>
İşlevi / Ne Amaçla Kullanılır: Bütün HTML kodlarını kapsayan ana kök etiketidir. İçindeki lang="tr" ifadesi tarayıcıya sayfa dilinin Türkçe olduğunu söyler.

3. Head (Başlık ve Ayar) Alanı ve Meta

<head>
    <meta charset="UTF-8">
    <title>Sınav Sayfası</title>
    <link rel="stylesheet" href="stil.css"> <!-- DIŞ CSS BAĞLAMA -->
</head>
İşlevi / Ne Amaçla Kullanılır: Sayfanın arka plan ayarlarını tutar, ekranda doğrudan görünmez. İçindeki <meta charset="UTF-8"> Türkçe karakterlerin düzgün çıkmasını sağlar. <link> etiketi ile dış CSS dosyası bağlanır.

4. Body (Gövde) Alanı

<body>
    <!-- Kullanıcının ekranda göreceği her şey buraya yazılır -->
</body>
İşlevi / Ne Amaçla Kullanılır: Web sitesinin ekranda görünen ana gövdesidir; yazılar, resimler, tablolar buraya eklenir.

5. Başlık Etiketleri (<h1> - <h6>)

<h1>Ana Başlık</h1>
<h6>En Küçük Başlık</h6>
İşlevi / Ne Amaçla Kullanılır: Metinlere başlık hiyerarşisi kazandırır. <h1> en büyük ve en önemli başlıktır, <h6> ise en küçük başlıktır.

6. Paragraf Etiketi (<p>)

<p>Bu bir paragraf metnidir.</p>
İşlevi / Ne Amaçla Kullanılır: Metinleri düzenli paragraflar halinde alt alta ayırmak ve blok oluşturmak için kullanılır.

7. Kalın ve İtalik Biçimlendirme Etiketleri

<strong>Kalın ve Önemli Metin</strong>
<em>Eğik ve Vurgulu Metin</em>
İşlevi / Ne Amaçla Kullanılır: Yazıyı kalın (<strong> veya <b>) ya da eğik/italik (<em> veya <i>) yapmak için kullanılır.

8. Üstü ve Altı Çizili Metinler

<del>100 TL</del> 
<ins>80 TL</ins>
İşlevi / Ne Amaçla Kullanılır: <del> metnin üstünü çizer, <ins> ise eklenmiş metin olarak altını çizer.

9. Üst ve Alt Simge Etiketleri

X<sup>2</sup>
H<sub>2</sub>O
İşlevi / Ne Amaçla Kullanılır: Matematiksel üst simgeler (sup) veya kimyasal formüllerdeki alt simgeler (sub) oluşturmak için kullanılır.

10. Listeleme Etiketleri (<ol>, <ul>, <dl>)

<ol type="A">
    <li>Birinci Madde</li>
</ol>

<ul type="square">
    <li>Madde</li>
</ul>

<dl>
    <dt>HTML</dt>
    <dd>Web dili başlığı</dd>
</dl>
İşlevi / Ne Amaçla Kullanılır: Verileri maddeler halinde listelemek içindir. <ol> sıralı liste yapar, <ul> sırasız liste yapar, <dl> ise terim-açıklama (tanım) listesi yapar.

11. Tablo Etiketleri (<table>) ve Hücre Birleştirme

<table border="1">
    <tr>
        <th rowspan="2">Başlık</th>
        <td colspan="2">Veri</td>
    </tr>
</table>
İşlevi / Ne Amaçla Kullanılır: Verileri satır ve sütunlar halinde düzenlemek içindir. colspan yan yana sütunları, rowspan alt alta satırları birleştirir. Sınavda CSS ile border-collapse: collapse; yazmayı unutma!

12. Div Etiketi ve Kutu Modeli (Margin - Padding)

<div id="kapsayici">
    Kutunun İçi
</div>
İşlevi / Ne Amaçla Kullanılır: Sayfayı kutulamak ve gruplamak için kullanılan boş blok kutudur.
width: Genişlik.
height: Yükseklik.
padding: İç boşluk (Yazının kutu kenarına uzaklığı).
margin: Dış boşluk (Kutunun diğer kutulara uzaklığı).
margin: 0 auto; Kutuyu sayfanın tam ortasına yerleştirir.

13. Medya Etiketleri (Resim ve Video)

<img src="foto.jpg" alt="Açıklama" width="200">

<video width="320" controls>
    <source src="video.mp4" type="video/mp4">
</video>
İşlevi / Ne Amaçla Kullanılır: Sayfaya görsel veya video eklemek içindir. <img> resim ekler (kapanış etiketi yoktur). <video> içindeki controls parametresi oynat/durdur butonlarını gösterir.

14. Link (<a>) Etiketi ve Butonlar

<!-- Sayfalar Arası Geçiş Linki -->
<a href="hakkimizda.html" target="_blank">Yeni Sekmede Aç</a>

<!-- Buton Görünümlü Link -->
<a href="#" style="padding: 10px 20px; background-color: blue; color: white; text-decoration: none;">Buton 1</a>
İşlevi / Ne Amaçla Kullanılır: <a> etiketi başka sayfalara geçiş sağlar. href gidilecek adresi, target="_blank" yeni sekmede açılmasını sağlar. Linki buton gibi yapmak için padding ve background-color verilir, text-decoration: none; ile alt çizgi kaldırılır.

15. ID (#) ve Class (.) Seçicileri Arasındaki Fark

/* ID: Sayfada SADECE 1 KEZ kullanılır */
#ana-kapsayici { width: 800px; }

/* Class: Sayfada BİRDEN FAZLA elemana verilebilir */
.kutu-tasarim { border: 1px solid #ccc; }
İşlevi / Ne Amaçla Kullanılır: id benzersiz nesneler içindir ve `#` ile çağrılır. class tekrar eden nesneler içindir ve `.` ile çağrılır. Sınavda hocalar genelde `id` kullanılması şartını koşar.

16. HTML5 Anlamsal (Semantic) Etiketler

<header>Üst Başlık ve Logo Alanı</header>
<nav>Menü Bağlantıları</nav>
<main>Ana İçerik Alanı</main>
<section>İçerik Bölümü</section>
<aside>Yan Menü / Yan Panel</aside>
<footer>Alt Bilgi ve Telif Alanı</footer>
İşlevi / Ne Amaçla Kullanılır: Sadece düz div kullanmak yerine arama motorlarının ve tarayıcıların sayfa yapısını daha iyi anlamasını sağlayan anlamsal yapı etiketleridir.
